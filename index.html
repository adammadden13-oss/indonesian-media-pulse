Metodologi Pemantauan

1. Teori Web Scraping & RSS

Tab: Nasional

Menggunakan pendekatan Automated Web Scraping dan parsing XML/RSS portal berita arus utama untuk ekstraksi metadata.

💡 Summary: Memetakan kecepatan dan volume publikasi media secara masif.

2. Teori Analisis Sentimen (NLP)

Tab: Sentimen

Menerapkan Lexicon-based approach dikombinasikan dengan TextBlob Polarity Scoring untuk polaritas teks.

💡 Summary: Mengukur kecemasan atau optimisme publik terhadap isu beredar.

3. Teori Agregasi Tren Lintas Platform

Tab: Tren

Mengambil rekam jejak kueri penelusuran harian dari Google Trends, X, dan TikTok RSS Feed.

💡 Summary: Menangkap topik perbincangan akar rumput sebelum diangkat media massa.

4. Teori Metadata Hiburan (TMDb)

Tab: Hiburan

Menghubungkan API resmi layanan hiburan global untuk mengambil peringkat film harian.

💡 Summary: Menyajikan perilaku konsumsi konten pop-culture masyarakat.
